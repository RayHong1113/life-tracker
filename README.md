# Life Tracker

An app to track how you spend your time and help you stay organized.

## 🚀 Tech Stack
* **Frontend**: Flutter (Dart)
* **State Management**: Provider / Riverpod
* **Local Database**: SQLite / Hive
* **Architecture**: MVVM (Model-View-ViewModel)

## 📌 Features (MVP)
* CRUD operations for daily habits.
* Seamless daily check-in and tracking system.
* Local persistent storage for offline-first user experience.
